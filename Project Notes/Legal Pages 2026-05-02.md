# Legal Pages

Date: 2026-05-02

## Scope

Added public MVC pages for TryOutSpot legal/compliance review:

- `/privacy-policy`
- `/terms-and-conditions`

## A2P 10DLC Notes

The pages include SMS-specific language for:

- Transactional TryOutSpot SMS program description
- Message frequency disclosure
- Message and data rates disclosure
- STOP opt-out instructions
- HELP support instructions
- Carrier delayed/undelivered message disclaimer
- SMS consent not being a condition of purchase
- Non-sharing clause for mobile information and text messaging opt-in data

## Review Note

These pages are intended as production-ready starting pages for deployment and Twilio A2P 10DLC campaign review, but they should still be reviewed by counsel before launch.
